# ✈️ FlightDeck QA

FlightDeck QA is a production-like flight booking system built as a long-term QA portfolio project.

The goal of the project is to practice the complete software testing workflow on a realistic application rather than isolated testing exercises.

## Project Goals

FlightDeck QA will be used to practice:

* Manual testing
* Test design
* Bug reporting
* REST API testing
* Database testing with SQL
* C#/.NET test automation
* UI automation with Playwright
* CI/CD with GitHub Actions

## Planned Features

The application will allow users to:

* Register and log in
* Search for available flights
* View flight details
* Create a booking
* View their bookings
* Cancel a booking

Administrators will be able to:

* Create flights
* Update flight information
* Manage available flights
